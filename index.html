Section 02 — How Daybreak Works
Scribe drafts. Humans approve.

Scribe

Drafts the daily brief from recent GitHub activity. Every statement links to evidence.

Read-only · Never invents work

Sentinel

Detects configured potential blockers and proposes follow-up actions.

Read-only · Recommends, does not execute

Clerk

Carries out approved GitHub actions and returns result links.

Write-capable · Acts only after human approval
